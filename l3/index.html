01 核心大觀念：收益法看「未來」

⏪ 比較法（上一堂）

根據過去的成交資料，找相似標地做四個調整，求得比較價格。
→ 看的是「過去」

⏩ 收益法（本堂）

透過折現方式，回推這項不動產未來能幫我賺多少錢，算出現在的收益價格。
→ 看的是「未來」

收益法之意義 §28
第一項：收益法得採直接資本化法、折現現金流量分析法等方法。
第二項：依前項方法所求得之價格為收益價格。
02 兩大方法 §28
§29 定義 ／ §30 公式

直接資本化法

P = A R

取勘估標地未來平均一年的客觀淨收益（A），除以當時適當的收益資本化率（R）。

A = 勘估標的未來平均一年期間之客觀淨收益
R = 收益資本化率
📊 算的是平均值
精選題：收益價格 1000 萬，淨收益 60 萬，求 r？
1000 = 60 r 　⟹　r = 6%
§31 定義 ／ §32 公式

折現現金流量分析法 DCF

P = Σ CFk (1+Y)k + Pn' (1+Y)n

適用以投資為目的的不動產評估。每期淨收益＋期末價值分別折現後加總。

P = 收益價格
CFk = 各期淨收益
k = 折現期數（第幾期）
Y = 折現率
Pn' = 期末價值（最後賣出的錢）
n = 持有總期數
💰 算的是每一期
03 DCF 折現觀念與計算實例
未來的 50 萬 ≠ 現在的 50 萬。第幾期就要折現幾次。期末價值也要按持有年數折現。

📌 賴哥投資案（老師例題）

賴哥投資別墅，每年淨收益 200 萬，預計第二年底以 2000 萬賣出，折現率 10%

第一年收益（CF₁）
200 萬
200 (1+10%)¹
第二年收益（CF₂）
200 萬
200 (1+10%)²
期末價值（Pn'）
2000 萬
2000 (1+10%)²
收益價格 P = 三者折現後相加

05 蒐集資料 §35 ⭐ 最近三年
第一項
收益法估價應蒐集勘估標地及與其特性相同或相似之比較標的最近三年間總收入、總費用及收益資本化率或折現率等資料。
第二項
前項蒐集最近三年間之資料有困難時，應於估價報告書中敘明。
第三項
蒐集第一項資料時，應就其合理性進行綜合研判，以確定資料之可用性，並得依其持續性、穩定性及成長情形加以調整。
第四項
前條蒐集總收入資料，得就其不動產之租金估計之，以確認總收入之合理性。
06 推算收入與費用 §36–42

§33 客觀淨收益定義

以「最有效使用」為基準，原則上採用契約租金。若契約租金未知，改採市場經濟租金。

§36 推算有效總收入

有效總收入 = 總收入 − 閒置損失 − 其他損失
例：100 − 10 = 90

§42 計算淨收益

淨收益 = 有效總收入 − 總費用
應扣除不屬於不動產所產生之其他淨收益。

07 折舊提存 §40–41 ⭐ 重要考點
勘估標地包含建物時，必須考慮折舊。以下兩大類，各有子公式，二擇一使用。

§40 等數折舊型【提存費】 最熱門

C × (1 − S) × 1 N

C = 總成本（重建成本）
S = 殘餘價格率（通常 10%）
N = 經濟耐用年數

→ 加在總費用中
精選題：耐用年數 50 年，殘餘價格率 10%，每年折舊為？
→ C × (1−10%) × 1 50

§41 等數折舊型【提存率】 熱門中的冷門

d = 1 − s N 1 − (1 − s) × n N

s = 殘餘價格率
N = 經濟耐用年數
n = 已經歷年數（屋齡）

→ 加在分母資本化率中
精選題：耐用 60 年、屋齡 20 年、殘值率 10%
→ 代入公式：(1−10%) × 1 60 ÷ [ 1 − (1−10%) × 20 60 ]

§40/41 償債基金型 冷門

提存費：C(1−S) × i (1+i)ᴺ − 1
提存率： i (1+i)ᴺ − 1
老師建議：背公式即可
⭐ 關鍵提醒：只有建物才有折舊，所以「折舊提存率」只加在建物的收益資本化率旁。土地不折舊！

風險溢酬法 常考

2

市場萃取法 常考

從市場實際交易案例反推。以已知收益（A）除以已知價格（P）求得 R。

P = A R 　→　R = A P
3

加權平均資金成本法（WACC）

依不同資金來源（自備款、貸款）的比例與利率加權計算。r = Σ Wi × Ki

精選題：小杜買商場，自備款 300 萬（利率5%），貸款 700 萬（利率10%）
r = 300 1000 × 5% + 700 1000 × 10% = 1.5% + 7% = 8.5%
4

債務保障比率法

R = 債務保障比率 × 貸款常數 × 貸款成數
5

有效總收入乘數法

R = 淨收益率 有效總收入乘數
09 各類標的收益價格 §44–46

🌱 土地收益價格 §44

土地無建物者： P = a r
土地有建物者： P = a₁ − a₂ r a₁=房地淨收益, a₂=建物淨收益
建物已扣折舊： P × r = a
建物未扣折舊： P × (r+d) = a

🏗️ 建物收益價格 §45

淨收益已扣折舊提存費： P = 建物淨收益 r
淨收益未扣折舊提存費： P = 建物淨收益 r + d r = 建物收益資本化率，d = 折舊提存率

🏠 房地收益價格 §46

第一項： P = 房地淨收益 房地綜合 R
第二項：46條重點公式
房地綜合 R =
土地 r × 土地價值比率
＋ (建物 r + d) × 建物價值比率
⭐ 核心原則：只有建物會折舊 → 折舊提存率 d 只加在建物端的資本化率，土地端不用加。
